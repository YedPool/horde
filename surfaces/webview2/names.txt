# What identifies the WebView2 surface. tools/HostNames.ps1 fails test/test-host-names.ps1 when any of
# these appears in a file outside surfaces/webview2/ (and outside the prose under planning/, by rule)
# that surfaces/webview2/allowlist.txt does not list, exactly as often as it lists (CONTRIBUTING rule 14;
# decisions design 2026-10-06, decision 2). Each is matched as a case-insensitive substring, on every
# line and on the file's path.
#
# name | why it identifies this surface
WebView2 | the web engine's own name: as a substring it also catches the package, its three files, every type of its interface, the engine's process and every Horde function named after it
chrome.webview | the object the engine gives a page to post messages through, which a page file outside this folder must never touch: it talks through the bridge this folder serves
horde.invalid | the made-up origin this surface serves every mount under, its private detail: a page that wrote it could be shown by this surface only, so a page addresses its files relatively (surfaces/Port.ps1, WHERE A PAGE FINDS A FILE)
#
# CONSIDERED AND LEFT OUT:
#   webview - a general word for a web page shown inside a program; another platform's surface will be one too.
#   WinForms - the window toolkit this surface happens to use; a surface with no web engine could use it as well.
