# THE REPO-WIDE GUARDS: the suites that read the whole repository, so any pull request can break them
# (CONTRIBUTING 15 rule 9). ONE LIST, TWO READERS: `horde merge` (cli/Merge.ps1) and the CI workflow
# (.github/workflows/guards.yml) both read this file, so adding a guard is one line here and nothing else.
#
# Format: one script per line, relative to the repository root, under test/ and ending .ps1. A # starts a
# comment; blank lines are ignored. A line that is not a script path refuses the whole list (a skipped
# line is a guard that silently does not run).
#
# Each guard runs in Windows PowerShell 5.1 AND in PowerShell 7 (the MSI install, never the Store copy),
# and is green only on exit 0 with a closing "==== ... ====" banner that is not a failures banner. A guard
# must therefore pass in both shells. horde merge also keeps every guard the BASE branch lists: a pull
# request may add a line, but removing one here does not stop it running.
#
