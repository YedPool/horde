# The files outside agents/claude-code/ that may name the claude-code harness, and exactly how many times
# (CONTRIBUTING rule 14; engine-settings design, 2026-09-30, section 9 and build step E1). A mention is
# one occurrence of any name in names.txt, plus one if the file's path has one. tools/HostNames.ps1
# fails test/test-host-names.ps1 on a file not listed here, on a listed file that names the harness
# more times than listed, and on an entry that allows more than its file needs - and, when the checkout
# has origin/main, on an entry origin/main lacks or a count above its count - so this list only grows
# through a reviewed record. When a mention goes, lower the count or delete the line. When one must be
# added, add or raise the entry here AND append a line to growth.txt in this folder -
# path | old -> new | YYYY-MM-DD | reason - with old being origin/main's count (0 for a new path).
#
# MEASURED, NOT WRITTEN BY HAND: every count below is what the shipped counting function
# (Get-HordeNameMentionCount in tools/HostNames.ps1) returned on 2026-09-30, when this list was made.
# Core names the harness today because Phases 0 to 2 read the old system's stores, which are the
# harness's own files. These entries shrink as those reads move behind the AgentPort (engine-settings
# steps E8 to E11); none may be added for new code.
#
# The .md and .html files under planning/ are not scanned, by rule (see tools/HostNames.ps1).
#
